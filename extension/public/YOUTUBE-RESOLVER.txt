YouTube resolver / YouTube 解析器

Song-source support / 歌曲音源识别：youtube-music-song-v1

Music links prefer a verified album recording; ordinary YouTube links keep
the original video's audio. Song/video counterpart mappings take priority.
For an unmapped official MV, title and artist channel IDs must match a
single album result. Unconfirmed matches stop with a clear message.
The resolved song ID is used for player context and all download refreshes.
No new browser permissions are requested. The AI installer is unchanged.

Music 链接优先读取经过确认的专辑歌曲，普通 YouTube 链接保留原视频音轨。
优先使用歌曲／视频对应关系；尚未建立对应关系的官方 MV 必须同时满足
歌名、艺术家频道 ID 和唯一专辑结果的校验。无法确认时停止并明确提示。
播放上下文和下载地址刷新全部使用实际歌曲 ID。不增加浏览器权限，
AI 安装包无需更新。项目版本仍为 v0.4.6，需要替换并重新加载扩展文件。

Maintenance reference: yt-dlp 2026.08.19; YouTube.js 18.0.0.
维护参考：yt-dlp 2026.08.19；YouTube.js 18.0.0。

This package reads plain and gzip player requests, refreshes the embedded
client version and per-video playback context when used, and does not reuse
a fixed test video's token for a different song. Retired Android VR and
TV-embedded fallbacks are excluded. No remote code or Python is loaded.

本包支持普通及 gzip 播放器请求，在使用时刷新嵌入客户端版本和本视频的
播放上下文，不会把固定测试视频的凭证复用于另一首歌。已移除失效的
Android VR 和 TV-embedded 回退；不会加载远程代码或 Python。

Unpacked extension users must replace the extracted package, reload the
extension in the browser extension manager, and refresh the editor tab.
There is no scheduled monitoring task. A new extraction algorithm still
requires a reviewed extension release; metadata refresh is automatic.

已解压扩展用户需要替换扩展文件，在浏览器扩展管理页重新加载，再刷新
编辑器标签页。没有定时监测任务。配置和凭证在使用时自动刷新，但全新的
解析算法仍需要经过验证后发布扩展更新。
