LRC Editor local AI engine for Linux / LRC Editor Linux 本机 AI 引擎

This archive is not a browser extension. / 这个压缩包不是浏览器扩展。
This archive contains only Unix launchers; Windows .cmd and .ps1 files are not included.
这个压缩包只包含 Unix 启动脚本，不再混入 Windows 的 .cmd 和 .ps1 文件。

Install / 安装：
1. Fully extract lrc-editor-ai-aligner-macos-linux-v0.4.6.tar.gz.
   完整解压 lrc-editor-ai-aligner-macos-linux-v0.4.6.tar.gz。
2. Open a terminal in the extracted directory and run: ./install-ai-aligner.sh
   在解压目录打开终端，运行：./install-ai-aligner.sh
3. Press Enter for the default directory, or enter an absolute path on another disk.
   直接按 Enter 使用默认目录，也可输入其他磁盘上的绝对路径。
4. Choose 1 for the official Hugging Face source or 2 for HF-Mirror. Mirror mode also covers Demucs with full official SHA-256 verification.
   选择 1 使用 Hugging Face 官方源，或选择 2 使用 HF-Mirror；镜像模式也覆盖 Demucs，并校验完整官方 SHA-256。
5. NVIDIA systems with at least 4 GB VRAM can use the isolated CUDA path; all other systems use CPU int8.
   至少 4 GB 显存的 NVIDIA 设备可使用隔离 CUDA；其他设备使用 CPU int8。

Use / 使用：
- Start: ./start-ai-aligner.sh
- Stop: ./stop-ai-aligner.sh
- Uninstall: ./uninstall-ai-aligner.sh
  卸载需要先输入 UNINSTALL，再完整输入安装路径，完成两次确认。

Chrome extension / Chrome 扩展：
1. Download and fully extract lrc-editor-media-bridge-v0.4.6.zip.
2. Open chrome://extensions and enable Developer mode.
3. Select Load unpacked and choose the extracted extension folder.
4. Reload https://lrc.sgmy.org after installing or updating.

Microsoft Edge and Chromium use their extension management page with the same Developer mode / Load unpacked steps.
